# 股票分析流程详解

> 核心文件: `src/core/pipeline.py` - StockAnalysisPipeline 类

---

## 一、流程概览

StockAnalysisPipeline 是整个系统的核心调度器，负责协调数据获取、分析、存储和通知的完整流程。

### 1.1 主要职责

1. **数据获取**: 协调多个数据源获取股票数据
2. **趋势分析**: 基于交易理念进行技术分析
3. **情报搜索**: 多维度新闻和风险排查
4. **AI 分析**: 调用 LLM 生成决策报告
5. **结果存储**: 保存分析历史
6. **通知推送**: 多渠道推送分析结果

## 三、核心方法

### 3.1 fetch_and_save_stock_data()

**功能**: 获取并保存单只股票数据

**断点续传逻辑**:
1. 检查数据库是否已有今日数据
2. 如果有且不强制刷新，则跳过网络请求
3. 否则从数据源获取并保存

```python
def fetch_and_save_stock_data(
    self,
    code: str,
    force_refresh: bool = False
) -> Tuple[bool, Optional[str]]:
    # 1. 获取股票名称
    stock_name = self.fetcher_manager.get_stock_name(code)

    # 2. 断点续传检查
    if not force_refresh and self.db.has_today_data(code, today):
        logger.info(f"{stock_name}({code}) 今日数据已存在，跳过获取")
        return True, None

    # 3. 从数据源获取数据
    df, source_name = self.fetcher_manager.get_daily_data(code, days=30)

    # 4. 保存到数据库
    saved_count = self.db.save_daily_data(df, code, source_name)

    return True, None
```

### 3.2 analyze_stock()

**功能**: 分析单只股票（增强版）

**完整流程**:

#### Step 1: 获取实时行情
```python
# 使用 DataFetcherManager 统一入口，自动故障切换
realtime_quote = self.fetcher_manager.get_realtime_quote(code)

if realtime_quote:
    # 提取量比、换手率
    volume_ratio = realtime_quote.volume_ratio
    turnover_rate = realtime_quote.turnover_rate
    logger.info(f"实时行情: 价格={realtime_quote.price}, "
                f"量比={volume_ratio}, 换手率={turnover_rate}%")
```

#### Step 2: 获取筹码分布
```python
# 带熔断保护
chip_data = self.fetcher_manager.get_chip_distribution(code)

if chip_data:
    logger.info(f"筹码分布: 获利比例={chip_data.profit_ratio:.1%}, "
                f"90%集中度={chip_data.concentration_90:.2%}")
```

#### Step 3: 模式判断
```python
# 判断是否启用 Agent 模式
use_agent = getattr(self.config, 'agent_mode', False)

# 自动启用条件: 配置了特定技能
if not use_agent:
    configured_skills = getattr(self.config, 'agent_skills', [])
    if configured_skills and configured_skills != ['all']:
        use_agent = True

if use_agent:
    # Agent 模式: ReAct 循环
    return self._analyze_with_agent(code, report_type, query_id,
                                     stock_name, realtime_quote, chip_data)
```

#### Step 4: 趋势分析（传统模式）
```python
# 获取历史数据（~60 个交易日用于 MA60）
end_date = date.today()
start_date = end_date - timedelta(days=89)
historical_bars = self.db.get_data_range(code, start_date, end_date)

if historical_bars:
    df = pd.DataFrame([bar.to_dict() for bar in historical_bars])

    # Issue #234: 盘中实时数据增强
    if self.config.enable_realtime_quote and realtime_quote:
        df = self._augment_historical_with_realtime(df, realtime_quote, code)

    # 趋势分析
    trend_result = self.trend_analyzer.analyze(df, code)
    logger.info(f"趋势分析: {trend_result.trend_status.value}, "
                f"买入信号={trend_result.buy_signal.value}")
```

#### Step 5: 多维度情报搜索
```python
if self.search_service.is_available:
    # 使用多维度搜索（最多5次搜索）
    intel_results = self.search_service.search_comprehensive_intel(
        stock_code=code,
        stock_name=stock_name,
        max_searches=5
    )

    # 格式化情报报告
    if intel_results:
        news_context = self.search_service.format_intel_report(
            intel_results, stock_name
        )

        # 保存新闻情报到数据库
        for dim_name, response in intel_results.items():
            if response and response.success:
                self.db.save_news_intel(
                    code=code,
                    name=stock_name,
                    dimension=dim_name,
                    query=response.query,
                    response=response,
                    query_context=query_context
                )
```

#### Step 6: 获取分析上下文
```python
# 从数据库获取技术面数据
context = self.db.get_analysis_context(code)

if context is None:
    # 无历史数据时的降级处理
    context = {
        'code': code,
        'stock_name': stock_name,
        'date': date.today().isoformat(),
        'data_missing': True,
        'today': {},
        'yesterday': {}
    }
```

#### Step 7: 增强上下文
```python
# 添加实时行情、筹码、趋势分析结果
enhanced_context = self._enhance_context(
    context,
    realtime_quote,
    chip_data,
    trend_result,
    stock_name
)
```

#### Step 8: AI 分析
```python
# 调用 Gemini 分析器
result = self.analyzer.analyze(
    enhanced_context,
    news_context=news_context
)

# 填充价格信息
if result:
    result.query_id = query_id
    realtime_data = enhanced_context.get('realtime', {})
    result.current_price = realtime_data.get('price')
    result.change_pct = realtime_data.get('change_pct')

    # Issue #589: chip_structure fallback
    if chip_data:
        fill_chip_structure_if_needed(result, chip_data)
```

#### Step 9: 保存分析历史
```python
if result and result.report:
    self.db.save_analysis_history(
        code=code,
        name=stock_name,
        report=result.report,
        sentiment_score=result.sentiment_score,
        trend_prediction=result.trend_prediction,
        operation_advice=result.operation_advice,
        query_context=query_context
    )
```

#### Step 10: 保存上下文快照（可选）
```python

    self.db.save_context_snapshot(
        code=code,
        name=stock_name,
        context=enhanced_context,
        news_context=news_context,
        query_id=query_id
    )
```

### 3.3 _analyze_with_agent()

**功能**: Agent 模式分析（ReAct 循环）

```python
def _analyze_with_agent(
    self,
    code: str,
    report_type: ReportType,
    query_id: str,
    stock_name: str,
    realtime_quote: Optional[Any],
    chip_data: Optional[ChipDistribution]
) -> Optional[AnalysisResult]:

    # 1. 构建 Agent 执行器
    from src.agent.factory import build_agent_executor
    executor = build_agent_executor(self.config)

    # 2. 构建用户消息
    user_message = f"分析股票 {stock_name}({code})"

    # 3. 执行 Agent（ReAct 循环）
    agent_result = executor.run(
        message=user_message,
        session_id=f"analysis_{query_id}"
    )

    # 4. 解析结果
    if agent_result.success and agent_result.dashboard:
        # 转换为 AnalysisResult
        result = self._convert_agent_result(
            agent_result,
            code,
            stock_name,
            query_id
        )
        return result

    return None
```

## 四、批量分析流程

### 4.1 process_stocks()

**功能**: 批量处理多只股票

```python
def process_stocks(
    self,
    stock_codes: List[str],
    force_refresh: bool = False,
    skip_analysis: bool = False,
    report_type: ReportType = ReportType.SIMPLE
) -> Dict[str, Any]:

    # 1. 数据获取阶段（并发）
    with ThreadPoolExecutor(max_workers=self.max_workers) as executor:
        fetch_futures = {
            executor.submit(
                self.fetch_and_save_stock_data,
                code,
                force_refresh
            ): code
            for code in stock_codes
        }

        # 等待所有数据获取完成
        for future in as_completed(fetch_futures):
            code = fetch_futures[future]
            success, error = future.result()
            # 记录结果

    # 2. 分析阶段（并发）
    if not skip_analysis:
        with ThreadPoolExecutor(max_workers=self.max_workers) as executor:
            analysis_futures = {
                executor.submit(
                    self.analyze_stock,
                    code,
```

## 五、关键辅助方法

### 5.1 _enhance_context()

**功能**: 增强分析上下文

```python
def _enhance_context(
    self,
    context: Dict[str, Any],
    realtime_quote: Optional[Any],
    chip_data: Optional[ChipDistribution],
    trend_result: Optional[TrendAnalysisResult],
    stock_name: str
) -> Dict[str, Any]:

    enhanced = context.copy()

    # 添加股票名称
    enhanced['stock_name'] = stock_name

    # 添加实时行情
    if realtime_quote:
        enhanced['realtime'] = {
            'price': realtime_quote.price,
            'change_pct': realtime_quote.change_pct,
            'volume_ratio': realtime_quote.volume_ratio,
            'turnover_rate': realtime_quote.turnover_rate,
            'source': realtime_quote.source.value
        }

    # 添加筹码分布
    if chip_data:
        enhanced['chip'] = {
            'profit_ratio': chip_data.profit_ratio,
            'concentration_90': chip_data.concentration_90,
            'avg_cost': chip_data.avg_cost
        }

    # 添加趋势分析
    if trend_result:
        enhanced['trend'] = {
            'status': trend_result.trend_status.value,
            'buy_signal': trend_result.buy_signal.value,
            'signal_score': trend_result.signal_score,
            'ma5': trend_result.ma5,
            'ma10': trend_result.ma10,
            'ma20': trend_result.ma20
        }

    return enhanced
```

### 5.2 _augment_historical_with_realtime()

**功能**: 盘中实时数据增强（Issue #234）

```python
def _augment_historical_with_realtime(
    self,
    df: pd.DataFrame,
    realtime_quote: Any,
    code: str
) -> pd.DataFrame:
    """
    将实时行情数据追加到历史数据末尾，用于盘中 MA 计算
    """
    # 检查是否在交易时间
    market = get_market_for_stock(code)
    if not is_market_open(market):
        return df

    # 构造今日实时数据行
    today_row = {
        'date': date.today(),
        'close': realtime_quote.price,
        'open': realtime_quote.open,
        'high': realtime_quote.high,
        'low': realtime_quote.low,
        'volume': realtime_quote.volume
    }

    # 追加到 DataFrame
    df_augmented = pd.concat([df, pd.DataFrame([today_row])], ignore_index=True)

    return df_augmented
```

## 六、错误处理

### 6.1 数据获取失败
- 记录错误日志
- 返回失败状态和错误信息
- 不影响其他股票的处理

### 6.2 分析失败
- 记录错误日志
- 跳过该股票
- 继续处理其他股票

### 6.3 通知失败
- 记录错误日志
- 不影响分析结果的保存

## 七、性能优化

### 7.1 并发控制
- 使用 ThreadPoolExecutor 并发处理
- 可配置 max_workers 控制并发数

### 7.2 断点续传
- 检查今日数据是否已存在
- 避免重复网络请求

### 7.3 数据缓存
- 数据库缓存历史数据
- 减少数据源访问频率

### 7.4 故障切换
- 实时行情多数据源自动切换
- 熔断保护避免雪崩

## 八、配置项

### 8.1 核心配置
- `max_workers`: 最大并发数

- `agent_skills`: Agent 技能列表
- `save_context_snapshot`: 是否保存上下文快照

### 8.2 数据源配置
- `enable_realtime_quote`: 是否启用实时行情
- `realtime_source_priority`: 实时行情数据源优先级
- `enable_chip_distribution`: 是否启用筹码分布

### 8.3 搜索配置
- `news_max_age_days`: 新闻最大时效（天）
- `bocha_api_keys`: Bocha API Keys
