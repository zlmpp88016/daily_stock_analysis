# 股票智能分析系统 - 项目概览

> 生成时间: 2026-03-15
> 分析范围: 项目结构、股票分析流程、Agent论股功能

---

## 一、项目定位

**基于 AI 大模型的 A股/港股/美股自选股智能分析系统**

- 每日自动分析并推送「决策仪表盘」到企业微信/飞书/Telegram/邮箱
- 支持多轮策略问答（Agent 问股功能）
- 内置交易纪律和策略系统

---

## 二、核心功能模块

### 2.1 AI 分析引擎
- **决策仪表盘**: 一句话核心结论 + 精确买卖点位 + 操作检查清单
- **多维度分析**: 技术面（盘中实时 MA/多头排列）+ 筹码分布 + 舆情情报 + 实时行情
- **市场覆盖**: A股、港股、美股及美股指数（SPX、DJI、IXIC 等）

### 2.2 策略系统
- **A股策略**: 三段式复盘策略（进攻/均衡/防守）
- **美股策略**: Regime Strategy（risk-on/neutral/risk-off）
- **内置交易纪律**:
  - 严禁追高（乖离率超阈值自动提示）
  - 趋势交易（MA5 > MA10 > MA20 多头排列）
  - 精确点位（买入价、止损价、目标价）

### 2.3 Agent 问股功能
- **多轮策略对话**: 支持均线金叉/缠论/波浪等 11 种内置策略
- **全链路支持**: Web/Bot/API
- **工具调用**: ReAct 循环，分阶段执行数据获取和分析

### 2.4 智能导入
- **多源导入**: 图片、CSV/Excel 文件、剪贴板粘贴
- **Vision LLM**: 提取代码+名称
- **置信度分层**: 自动确认和名称解析

### 2.5 自动化与推送
- **定时运行**: GitHub Actions 定时执行
- **多渠道通知**: 企业微信、飞书、Telegram、钉钉、邮件、Pushover
- **回测验证**: 自动评估历史分析准确率

---

## 三、技术栈

### 3.1 AI 模型
- **统一调用**: LiteLLM（支持多 Key 负载均衡）
- **支持模型**: AIHubMix、Gemini、OpenAI 兼容、DeepSeek、通义千问、Claude 等

### 3.2 数据来源
- **行情数据**: AkShare、Tushare、Pytdx、Baostock、YFinance
- **新闻搜索**: Tavily、SerpAPI、Bocha、Brave、MiniMax

### 3.3 核心框架
- **后端**: Python 3.10+, FastAPI
- **前端**: React (Web Chat 界面)
- **数据库**: SQLite (本地存储)
- **并发**: ThreadPoolExecutor

## 五、核心数据流

### 5.1 股票分析流程
```
用户请求
    ↓
StockAnalysisPipeline (pipeline.py)
    ↓
├─ 数据获取 (DataFetcherManager)
│   ├─ 实时行情 (量比、换手率)
│   ├─ 筹码分布
│   └─ 历史K线数据
    ↓
├─ 趋势分析 (StockTrendAnalyzer)
│   └─ MA5/MA10/MA20 多头排列判断
    ↓
├─ 情报搜索 (SearchService)
│   └─ 多维度新闻搜索（最新消息+风险排查+业绩预期）
    ↓
├─ AI 分析 (GeminiAnalyzer 或 AgentExecutor)
│   ├─ 传统模式: 单次 LLM 调用
│   └─ Agent 模式: ReAct 循环 + 工具调用
    ↓
├─ 结果存储 (Database)
    ↓
└─ 通知推送 (NotificationService)
```

### 5.2 Agent 问股流程
```
用户消息 (/chat 或 Web)
    ↓
AgentExecutor (executor.py)
    ↓
├─ 阶段1: 行情与K线
│   ├─ get_realtime_quote (实时行情)
│   └─ get_daily_history (历史K线)
    ↓
├─ 阶段2: 技术与筹码
│   ├─ analyze_trend (技术指标)
│   └─ get_chip_distribution (筹码分布)
    ↓
├─ 阶段3: 情报搜索
│   └─ search_stock_news (新闻搜索)
    ↓
├─ 阶段4: 生成报告
│   └─ 输出决策仪表盘 JSON
    ↓
└─ 返回结果
    ├─ Web: ChatPage.tsx 渲染
    ├─ Bot: /chat 命令响应
    └─ API: /api/v1/agent/chat 接口
```

## 六、关键特性

### 6.1 分析模式切换
- **传统模式**: 单次 LLM 调用，适合批量分析
- **Agent 模式**: ReAct 循环，适合交互式问答
- **自动切换**: 配置 `AGENT_MODE=true` 或指定 `agent_skills`

### 6.2 数据容错
- **断点续传**: 检查今日数据是否已存在
- **故障切换**: 实时行情多数据源自动切换
- **熔断保护**: 筹码分布获取带熔断机制

### 6.3 并发控制
- **ThreadPoolExecutor**: 多股票并发分析
- **max_workers**: 可配置并发数

### 6.4 会话管理
- **ConversationManager**: 管理多轮对话会话
- **TTL**: 30 分钟会话过期
- **持久化**: 消息历史存储到数据库

## 七、部署方式

1. **GitHub Actions**: 定时执行，零成本
2. **Docker**: 容器化部署
3. **本地运行**: Python 环境直接运行

## 八、配置要点

### 8.1 必需配置
- **AI 模型**: 至少配置一个（Gemini/OpenAI/Claude）
- **股票列表**: `STOCK_CODES` 环境变量

### 8.2 可选配置
- **通知渠道**: 企业微信/飞书/Telegram 等
- **数据源**: Tushare Token、实时行情优先级
- **搜索服务**: Tavily/SerpAPI API Key
- **Agent 模式**: `AGENT_MODE=true`
