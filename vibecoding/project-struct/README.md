## 🎯 核心发现

### 1. 双模式架构

**传统模式**:
- 单次 LLM 调用
- 适合批量分析
- 快速响应

**Agent 模式**:
- ReAct 循环 + 工具调用
- 适合交互式问答
- 深度分析

### 2. 分阶段执行

**股票分析流程**:
```
数据获取 → 趋势分析 → 情报搜索 → AI 分析 → 结果存储 → 通知推送
```

**Agent 工作流程**:
```
阶段1: 行情与K线 → 阶段2: 技术与筹码 → 阶段3: 情报搜索 → 阶段4: 生成报告
```

### 3. 数据容错机制

- **断点续传**: 避免重复获取今日数据
- **故障切换**: 多数据源自动切换
- **熔断保护**: 筹码分布获取带熔断
- **降级处理**: 数据缺失时的降级策略

### 4. 多渠道集成

- **Web**: React 前端 + FastAPI 后端
- **Bot**: 企微/飞书/Telegram 命令系统
- **API**: RESTful 接口
- **定时任务**: GitHub Actions 自动执行

## 📝 使用指南

### 快速开始

1. **配置环境变量**:
   ```bash
   GEMINI_API_KEY=your_key
   STOCK_CODES=600519,000001
   AGENT_MODE=true
   ```

2. **启动服务**:
   ```bash
   python main.py --mode api
   ```

3. **访问 Web 界面**:
   ```
   http://localhost:8000/chat
   ```

### API 调用示例

```bash
# Agent 对话
curl -X POST http://localhost:8000/api/v1/agent/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "分析茅台", "session_id": "user123"}'

# 股票分析
curl -X POST http://localhost:8000/api/v1/stocks/analyze \
  -H "Content-Type: application/json" \
  -d '{"codes": ["600519"], "full_report": true}'
```
